# Manejo_Archivos (primer proyecto)

Este repositorio conserva un ejercicio inicial de archivos de texto
(`archivosTexto`) hecho en Java.

El proyecto ampliado y mantenido ahora está en:

**https://github.com/Sebitas13/java-file-handling-lab**

Ese repo incluye Maven, Java 21, JUnit, CI, README de portafolio y una versión
sanitizada de los ejercicios de manejo de archivos.

Este repositorio se mantiene como historial de aprendizaje.
